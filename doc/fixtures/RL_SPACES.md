# RL spaces fixtures

`rl_spaces.json` lets an environment outside this crate check its use of the `rl`
spaces. It is generated by `tests/rl_external.rs`, which also checks it on every test
run; rewrite it with `MM_WRITE_RL_FIXTURES=1 cargo test --features rl --test rl_external`
only after a deliberate change of a space version.

- `profiles`: each declared profile as plain data, with the hex of `RlSpec::to_bytes`, its
  `SpecId` (fingerprint as a decimal string) and `RlSpec::action_head_sizes`.
- `observations`: plain inputs of `observation_features` (the observation, the previous
  row and the tick size) with the expected raw values and normalized `f32` values.
- `actions`: rows of head values with the action `RlSpec::decode_action` gives and its
  canonical row from `RlSpec::encode_action`, or the error.

Decimals are strings. Each `f32` is a string in its shortest round trip form.
