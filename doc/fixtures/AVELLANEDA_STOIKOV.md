# Avellaneda Stoikov fixtures

`avellaneda_stoikov.json` pins the outputs of the Avellaneda Stoikov quoting functions in
`strategy::avellaneda_stoikov`. The crate embeds it as
`market_maker_rs::strategy::avellaneda_stoikov::AVELLANEDA_STOIKOV_FIXTURES`. It is
generated by `tests/avellaneda_stoikov_golden.rs`, which also checks it on every test
run; CI runs that test on x86_64 and on aarch64, so both check the same file. Rewrite it
with `MM_WRITE_AS_FIXTURES=1 cargo test --test avellaneda_stoikov_golden` only after a
deliberate change of the arithmetic, then run the test once more without the variable to
check the embedded copy.

- `format`: the version of this file's layout (2).
- `log_ratio_significant_digits`: the significant digits kept, half to even, of
  `log1p(γ/k) / (γ/k)` (`LOG_RATIO_SIGNIFICANT_DIGITS`).
- `cases`: a grid over mid price, inventory (flat, long, short), risk aversion `γ`
  (including very small values, so small `γ/k`), volatility `σ`, time to terminal in
  milliseconds (including 0) and order intensity `k`. Each case has its `input` and the
  `expected` reservation price, spread, bid and ask from `calculate_reservation_price`,
  `calculate_optimal_spread` and `calculate_optimal_quotes`. The grid ends with inputs
  each function refuses: non positive inputs, `γ / k` underflowing to zero, overflows
  and a bid that is not positive.
- `log_ratio`: the ratio `L = log1p(x) / x` for log spaced `x` from 1e-20 to 1e20 (five
  per decade) and the neighbourhoods of `sqrt(2) - 1` and `2^-29`, where `log1p`
  switches code paths. Each row gives `x`, `ratio_f64_bits` (the hex of `f64::to_bits`
  of the unrounded ratio, 16 digits) and `rounded`, the `Decimal` the quotes use.
  `rounded` keeps 12 significant digits; below an `L` of 1e-16 (`x` above about 4e17) it
  is rounded half to even to 28 decimal places instead, the most `Decimal` holds.

Decimals are strings in `Decimal`'s `Display` form. A refused computation is
`{"error": "<MMError variant>"}` instead of a string.
